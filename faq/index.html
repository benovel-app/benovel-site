常見問題

你可能想先知道

BeNovel 是免費的嗎？

是。BeNovel Beta 可免費使用；若未來方案有所調整，會在下載前清楚說明，不會在未告知的情況下收費。

不使用 AI 也能寫作嗎？

可以。章節管理、角色與世界觀、正文編輯、閱讀、評論及匯出都不需要設定 AI；只有你主動啟用輔助功能時才會連線到所選服務。

作品會儲存在哪裡？

作品預設儲存在你選擇的本機作品資料夾。網站無法讀取你的原稿；只有你主動使用 AI、回饋或選用 GitHub 備份時，相關資料才會交給對應的第三方服務。

使用 BeNovel 一定要連上網路嗎？

不用。核心寫作功能可離線使用，作品資料會儲存在你選擇的本機資料夾；只有你主動使用需要連線的選用功能時才需要網路。

支援哪些語言與格式？

介面支援繁體中文、English 與日本語。作品可匯出為 Markdown、TXT、DOCX 或 BeNovel 作品封包。

支援哪些作業系統？

目前支援 Windows 10／11 與 macOS。正式使用重要原稿前，仍建議先以測試資料夾確認環境相容性。

可以從原作建立續集或外傳嗎？

可以。你能從既有作品建立續集、前傳、間章、後日談、外傳或同世界觀作品，並選擇承接主要角色等創作資料。
