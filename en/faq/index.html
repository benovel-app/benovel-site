FAQ

What writers ask before they begin

Is BeNovel free?

Yes. The BeNovel Beta is free to use. If pricing changes in the future, it will be explained clearly before download; you will not be charged without notice.

Can I write without AI?

Absolutely. Chapter planning, characters and lore, prose editing, reading, comments, and export work without any AI setup. A connection is made only when you choose to use an optional AI feature.

Where are my manuscripts stored?

Your work stays in the local project folder you choose. This website cannot read it. Data reaches a third party only when you actively use AI, send feedback, or enable optional GitHub backup.

Do I need an internet connection to use BeNovel?

No. Core writing features work offline, and your project data stays in the local folder you choose. You only need a connection when you actively use an optional online feature.

Which languages and formats are supported?

The interface supports Traditional Chinese, English, and Japanese. You can export Markdown, TXT, DOCX, or a BeNovel project package.

Which operating systems are supported?

BeNovel currently supports Windows 10/11 and macOS. Test it with a sample folder before using it on an important manuscript.

Can I create a sequel or spin-off from an existing work?

Yes. You can create a sequel, prequel, interlude, after story, spin-off, or shared-world work and choose which story context to carry over.
