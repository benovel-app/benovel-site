Privacy Policy

Last updated: July 10, 2026

This policy explains how the BeNovel product website and BeNovel desktop app handle data. We follow data-minimization and user-control principles: manuscripts stay on your device by default, and only the data needed for a feature is handled by another service when you actively choose that feature or contact us.

Local manuscripts and the website boundary

By default, the BeNovel app stores manuscripts, chapters, characters, lore, and settings in the local project folder you choose. This static product website cannot browse, read, or synchronize files on your computer. You remain responsible for file permissions and independent backups.

Data handled by this website

  • The site currently has no first-party accounts, advertising trackers, or behavioral analytics, and does not intentionally set advertising cookies.
  • This site is hosted on GitHub Pages. GitHub may process IP addresses, request times, browser details, and error logs as needed to deliver, secure, and operate the service. That processing is governed by GitHub's policy.
  • Coffee Oracle stores only the locale, date, selected result indexes, and lucky number in browser localStorage so the same browser shows the same result for that day. The oracle does not send this record to BeNovel.

Optional AI assistance

AI is not required for the core writing workflow. Only when you configure and invoke an AI service may the prompt, text you select or provide, necessary context, and technical parameters for that request be sent directly to the third-party provider you chose. How that provider logs, retains, or uses data depends on your account plan, settings, and its policy. Do not submit confidential or personal data that you do not want that provider to process.

Optional GitHub backup and external downloads

Project content is sent to GitHub only when you actively configure backup or sync, and it goes to the repository you select. Repository visibility, permissions, and data handling are governed by your GitHub settings and GitHub's policy. Installers may be delivered through GitHub Releases, where GitHub processes connection and account data under its own policy.

Email, feedback, and bug reports

If you email us or use the multilingual feedback form, we may receive your email address, message, attachments, and any app version, operating system, reproduction steps, or diagnostics you choose to provide. We use them only to reply, fix issues, improve the product, maintain security, or arrange an interview with your consent. Do not attach unrelated full manuscripts, API keys, passwords, or other sensitive data.

Third parties and international processing

BeNovel uses GitHub Releases, optional GitHub backup, and a clearly identified multilingual Google Forms feedback form. AI providers are selected by the user. These providers may process data in other countries or regions; their safeguards, retention periods, deletion tools, and rights procedures are governed by their policies and your account settings.

Retention, security, and deletion

We do not sell email addresses, feedback, or manuscripts. Contact and report data received directly by us is kept only as long as needed to address the issue, protect the service, and meet necessary obligations, and is reviewed for deletion when no longer needed. Contact benovel.official@gmail.com to request access, correction, or deletion of data you actively submitted. We may verify your identity before acting to prevent unauthorized deletion. Data held by a third party must be managed through that provider's tools or process.

Your choices

  • Use the core writing, planning, reading, and export tools without configuring AI.
  • Keep projects off GitHub by leaving GitHub backup unconfigured.
  • Clear this site's localStorage in your browser settings to reset the local Coffee Oracle record.
  • Contact benovel.official@gmail.com with questions about data handling.

Policy changes

We will update this page and its last-updated date when data practices, third-party services, or relevant product features change. When a change materially affects existing users, we will provide notice through the website or release notes where reasonably practical.
