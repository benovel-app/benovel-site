Install

How to install

  1. Wait for the public test download link to open.
  2. Run the installer for your OS, or unzip and launch BeNovel.
  3. Before your first real project, create a test folder.
  4. For real work, back up the original files first.
  5. If something breaks, submit the version, OS, and repro steps via the feedback page.
