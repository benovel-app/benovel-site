The writing workspace you'll see after installing

BeNovel centers on a local work, keeping the draft, characters, worldbuilding, comments, optional suggestions, and export in one desktop workflow.

Install

How to install

  1. Use the download button to open GitHub Releases and choose the installer for your OS.
  2. Run the installer for your OS, or unzip and launch BeNovel.
  3. Before using it on important work, create a test folder.
  4. For important manuscripts, back up the original files first.
  5. If something breaks, submit the version, OS, and repro steps via the feedback page.
