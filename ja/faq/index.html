よくある質問

よく寄せられる質問

BeNovel は無料ですか？

はい。BeNovel Beta は無料で利用できます。将来、料金体系を変更する場合はダウンロード前に明確にお知らせし、事前の案内なく料金が発生することはありません。

原稿はどこに保存されますか？

原稿は、あなたが選んだローカルの作品フォルダに保存されます。このウェブサイトから原稿を読むことはできません。外部サービスへ送られるのは、あなたがバックアップや任意の支援機能、フィードバックを明示的に利用した場合だけです。

BeNovel を使うにはインターネット接続が必要ですか？

いいえ。基本的な執筆機能はオフラインで利用でき、作品データは選択したローカルフォルダに保存されます。接続が必要なのは、任意のオンライン機能を利用するときだけです。

どの言語に対応していますか？

表示言語は繁體中文・English・日本語に対応します。このページの製品画像は、ルビや縦書きを含む日本語 UI の実際の画面です。

どの形式で書き出せますか？

作品全体・章・小節を Markdown、TXT、DOCX、または BeNovel 作品パッケージとして書き出せます。

対応 OS は？

現在は Windows 10／11 と macOS に対応します。大切な原稿に使う前に、テスト用フォルダで動作を確認してください。

ルビや縦書きに対応していますか？

はい。本文にルビを付け、縦書きの見開きで読み返せます。DOCX はルビを含む縦書き書き出しに対応し、400字詰め原稿用紙の枚数も確認できます。
