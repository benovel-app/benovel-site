プライバシーポリシー

最終更新日：2026年7月10日

本ポリシーは、BeNovel 製品サイトとデスクトップアプリにおけるデータの取り扱いを説明するものです。必要最小限の処理とユーザー自身の選択を原則とし、原稿は初期設定では端末内に保存されます。外部サービスがデータを扱うのは、ユーザーが該当機能を明示的に利用した場合に限られます。

ローカル原稿とウェブサイトの範囲

BeNovel アプリは、原稿、章、人物、世界観、設定を、ユーザーが選んだローカルの作品フォルダに保存します。本サイトは静的な製品サイトであり、ユーザーのコンピューター内にある作品を閲覧、取得、同期することはできません。ファイル権限と独立したバックアップはユーザー自身で管理してください。

本サイトが扱うデータ

  • 現在、本サイトには独自アカウント、広告トラッカー、行動分析ツールはなく、広告目的の Cookie を意図的に設定していません。
  • 本サイトは GitHub Pages でホストされています。GitHub は配信、セキュリティ、運用に必要な範囲で、IP アドレス、アクセス時刻、ブラウザー情報、エラーログを処理する場合があります。
  • 珈琲占いは、同じブラウザーで当日の結果を再表示するため、言語、日付、結果の番号、ラッキーナンバーだけを localStorage に保存します。この記録が占い機能から BeNovel に送信されることはありません。

任意の外部執筆支援

外部の執筆支援サービスは、基本的な執筆機能を使うための必須条件ではありません。ユーザーがサービスを設定し、明示的に実行した場合にのみ、その処理に必要な指示、選択または入力した文章、必要な文脈、技術的パラメーターが、選択した第三者サービスへ直接送信される場合があります。記録、保存、サービス改善への利用は、利用プラン、設定、各事業者のポリシーによって異なります。機密情報や不要な個人情報は送信しないでください。

任意の GitHub バックアップと外部ダウンロード

GitHub のバックアップまたは同期をユーザーが明示的に設定した場合にのみ、選択した作品が指定の GitHub リポジトリへ送信されます。公開範囲、権限、データの取り扱いは、ユーザーの GitHub 設定と GitHub のポリシーに従います。インストーラーを GitHub Releases から提供する場合、接続情報やアカウント情報は GitHub の方針に基づいて処理されます。

メール、フィードバック、不具合報告

メールまたは多言語フィードバックフォームを利用した場合、メールアドレス、本文、添付ファイル、および任意で提供されたアプリのバージョン、OS、再現手順、診断情報を受け取ることがあります。これらは返信、問題修正、製品改善、セキュリティ維持、同意を得たインタビューのためだけに利用します。問題と無関係な原稿全文、API キー、パスワード、その他の機密情報は添付しないでください。

第三者サービスと国外での処理

BeNovel は GitHub Releases、任意の GitHub バックアップ、明示した Google Forms の多言語フィードバックフォームを利用します。外部の執筆支援サービスはユーザーが選択します。各事業者は他の国や地域でデータを処理する場合があり、安全対策、保存期間、削除方法、権利行使の手順は、各社のポリシーとユーザーのアカウント設定に従います。

保存、安全、削除

メールアドレス、フィードバック、原稿を販売することはありません。直接受け取った問い合わせや報告は、問題対応、安全維持、必要な義務の履行に必要な期間だけ保管し、不要になったデータは定期的に削除します。ユーザーが自ら提供したデータの確認、訂正、削除を希望する場合は benovel.official@gmail.com までご連絡ください。不正な削除を防ぐため、本人確認をお願いする場合があります。第三者サービス内のデータは、各サービスの機能または手続きで管理してください。

ユーザーが選べること

  • 外部の執筆支援を設定せずに、基本的な執筆、管理、読書、書き出し機能を利用する。
  • GitHub バックアップを設定せず、作品を GitHub に送信しない。
  • ブラウザー設定から本サイトの localStorage を削除し、珈琲占いのローカル記録をリセットする。
  • データの取り扱いについて benovel.official@gmail.com に問い合わせる。

ポリシーの変更

データの取り扱い、第三者サービス、関連する製品機能に重要な変更がある場合は、本ページと最終更新日を更新します。既存ユーザーに大きく影響する変更は、合理的に可能な範囲でウェブサイトまたはリリースノートでも案内します。
