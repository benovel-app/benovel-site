隱私權政策

最後更新：2026 年 7 月 10 日

本政策說明 BeNovel 產品網站與 BeNovel 桌面 App 如何處理資料。我們以資料最小化與使用者主動控制為原則：作品預設留在你的裝置，只有在你主動啟用特定功能或聯絡我們時，必要資料才會交由相應服務處理。

本機作品與網站的界線

BeNovel App 預設將原稿、章節、角色、世界觀與設定儲存在你選擇的本機作品資料夾。本網站是靜態產品網站，無法瀏覽、讀取或同步你電腦中的作品內容。請自行管理檔案權限與獨立備份。

網站目前處理的資料

  • 本站目前不使用自建帳號、廣告追蹤器或行為分析工具，也不主動設定廣告 Cookie。
  • 本站透過 GitHub Pages 託管。GitHub 可能基於傳輸、安全與維運需要處理 IP 位址、請求時間、瀏覽器類型及錯誤紀錄；此類處理由 GitHub 的政策約束。
  • 你使用咖啡占卜時，瀏覽器 localStorage 只會保存語言、日期、抽籤項目索引與幸運數字，讓同一瀏覽器在當天顯示相同結果；資料不會因占卜功能傳送給 BeNovel。

選用的 AI 輔助功能

AI 功能預設不是寫作流程的必要條件。只有在你主動設定並呼叫 AI 服務時，完成該次請求所需的提示、你選取或提供的文字、必要上下文與技術參數，才可能直接傳送至你選擇的第三方 AI 服務。該服務如何記錄、保留或用於改善模型，取決於你的帳戶方案、設定與服務商政策；提交前請勿包含不希望交由該服務處理的機密或個人資料。

選用的 GitHub 備份與外部下載

只有在你主動設定 GitHub 備份或同步時，所選作品內容才會傳送到你指定的 GitHub 儲存庫，並受該儲存庫權限與 GitHub 政策約束。安裝檔可能透過 GitHub Releases 提供；造訪下載頁或 GitHub 時，GitHub 會依其政策處理連線與帳戶資料。

電子郵件、回饋與錯誤回報

當你寄信或使用多語回饋表單時，我們可能收到你的電子郵件地址、訊息內容、附件，以及你自願提供的 App 版本、作業系統、重現步驟與診斷資訊。資料只用於回覆、修復問題、改善產品、維護安全，或在取得同意後安排訪談。請不要附上與問題無關的完整原稿、API 金鑰、密碼或其他敏感資料。

第三方服務與跨境處理

BeNovel 使用 GitHub Releases、選用的 GitHub 備份，以及清楚標示的 Google Forms 多語回饋表單；AI 功能則由你自行選擇服務商。這些業者可能在不同國家或地區處理資料，其安全措施、保存期間、刪除方式與權利申請程序以各業者政策及你的帳戶設定為準。

保存、安全與刪除

我們不販售電子郵件、回饋或原稿。直接收到的聯絡與回報資料僅保留於處理問題、維護安全及履行必要義務所需期間，並定期刪除不再需要的資料。你可以透過 benovel.official@gmail.com 要求查詢、更正或刪除你曾主動提供的資料；為避免誤刪，我們可能先確認請求者身分。第三方服務中的資料須另依該服務提供的工具或程序處理。

你的選擇

  • 不設定 AI，仍可使用核心寫作、管理、閱讀與匯出功能。
  • 不設定 GitHub，作品就不會因備份功能上傳至 GitHub。
  • 可在瀏覽器設定中清除本站 localStorage，重設咖啡占卜的本機紀錄。
  • 若對資料處理有疑問，可聯絡 benovel.official@gmail.com。

政策變更

當資料處理方式、第三方服務或產品功能有重要變更時，我們會更新本頁與最後更新日期。若變更會明顯影響既有使用者，我們會在合理可行的範圍內透過網站或版本說明提供提示。
